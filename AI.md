# AI assistance in Orbit Space Program

Orbit Space Program was developed with AI assistance through an iterative process of project direction, code generation, feedback, and revision. The project creator supplied requirements, examples, and visual assets, and guided changes by reviewing the game and reporting issues.

## How AI contributed

- Generated and revised JavaScript, HTML, and CSS for game features and the interface in response to the creator's requests.
- Helped implement rocket-building calculations and simplified orbital-flight mechanics using the scientific references documented in the project.
- Investigated reported problems, including asteroid collisions and spaceship knockback, and proposed and implemented code fixes.
- Ran JavaScript syntax checks and automated checks for selected collision scenarios, and helped package updated project files.
- Helped document scientific sources and distinguish reference data from gameplay settings.

## Direction and review

The creator determined the requested features and changes, supplied feedback on how the game behaved, and requested revisions when results did not meet expectations. AI-generated changes were part of this review process; automated checks alone do not establish that every feature works correctly or that the simulation is scientifically accurate.

## Scientific references and game design

The scientific references recorded in `assets/js/data.js` and `SCIENCE.md` are NASA-hosted sources. AI helped incorporate and explain these references; it is not the source of the scientific measurements.

The game also contains custom design choices, including credits, progression, collision damage, asteroid placement, and compressed time and distance scales. These settings support gameplay and should not be presented as NASA measurements or a validated mission-planning simulation.
